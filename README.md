# 🚗 Intelligent Traffic Monitoring System

AI-based web application to detect vehicles in traffic videos using YOLO and OpenCV.

## 🛠️ Tech Stack
Python, OpenCV, YOLOv8 (Ultralytics), PyTorch, Flask, HTML, CSS, JavaScript

## 🚀 Run Locally
git clone https://github.com/TheGravityFalls-11/Intelligent-Traffic-Monitoring-System.git
cd Intelligent-Traffic-Monitoring-System

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python app.py

Open in browser:
http://127.0.0.1:5000/
